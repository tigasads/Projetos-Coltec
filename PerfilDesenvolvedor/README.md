# Cartão de Perfil de Desenvolvedor

Projeto desenvolvido com HTML e CSS, com o objetivo de praticar conceitos fundamentais de estruturação e estilização de páginas web.

## Tecnologias utilizadas

- HTML5
- CSS3

## Conceitos praticados

- Estruturação de páginas com HTML semântico.
- Estilização de elementos utilizando CSS.
- Flexbox para alinhamento e distribuição de elementos.
- Posicionamento de elementos com `position: relative` e `position: absolute`.
- Utilização de cores, espaçamentos, bordas e arredondamentos.
- Organização de elementos por meio de seletores CSS.

## Funcionalidades

- Exibição de um cartão de perfil.
- Apresentação de imagem e informações do desenvolvedor.
- Organização de habilidades em uma lista.
- Botão de interação posicionado no cartão.

## Como executar

1. Clone o repositório:

   ```bash
   git clone URL_DO_REPOSITORIO
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd nome-do-projeto
   ```

3. Abra o arquivo `index.html` no navegador.
